# 작업 체크리스트 템플릿

> 모든 서브 에이전트는 작업 시작 전과 완료 후 이 체크리스트를 작성/검토해야 합니다.

---

## Phase 1: 작업 시작 전 (Pre-Flight)

### 1.1 컨텍스트 확인
- [ ] `AGENTS.md`의 프로젝트 규칙을 확인했는가?
- [ ] `DESIGN.md`의 디자인 시스템을 확인했는가?
- [ ] `CLAUDE.md`의 Plan Mode/서브 에이전트 규칙을 확인했는가?
- [ ] 관련된 기존 코드를 탐색했는가? (`Agent(explore)` 활용 권장)

### 1.2 작업 범위 정의
- [ ] 이번 작업의 목표가 명확한가?
- [ ] 작업에 영향을 받는 파일/폴더를 식별했는가?
- [ ] 작업이 다른 기능과 충돌하지 않는가?

### 1.3 계획 수립
- [ ] 작업 단계를 3~5개로 분해했는가?
- [ ] 각 단계의 예상 소요 시간을 추정했는가?
- [ ] 중간에 막힐 경우의 대안(Plan B)을 고려했는가?

---

## Phase 2: 작업 완료 후 (Post-Flight)

### 2.1 기능 검증
- [ ] 요구사항에 정의된 모든 기능이 구현되었는가?
- [ ] 수동/자동으로 기능을 테스트했는가?
- [ ] 에러 상황도 테스트했는가?

### 2.2 코드 품질
- [ ] `npm run build`가 통과하는가?
- [ ] 새로운 TypeScript 타입 에러가 없는가?
- [ ] 사용하지 않는 import/변수가 없는가?
- [ ] 코드 포맷팅이 일관적인가?

### 2.3 디자인 시스템 준수
- [ ] Pretendard 폰트가 적용되었는가?
- [ ] CITI Blue (`--primary`) 색상이 올바르게 사용되는가?
- [ ] 모든 박스 요소에 rounded가 적용되었는가?
- [ ] 화면 정렬(`max-w-screen-xl`, `mx-auto`)이 유지되는가?

### 2.4 보안 & 안전성
- [ ] API Key/Secret이 클라이언트에 노출되지 않는가?
- [ ] 사용자 입력값이 검증/살균되었는가?
- [ ] `.env.local`이 Git에 포함되지 않았는가?

### 2.5 문서화
- [ ] 복잡한 로직에 주석이 있는가?
- [ ] API 변경 시 관련 문서(README, AGENTS.md)를 업데이트했는가?
- [ ] `.env.local.example`에 새로운 환경 변수를 추가했는가?

---

## Phase 3: 최종 검토 (Review)

### 3.1 자체 리뷰
- [ ] 내가 작성한 코드를 "처음 보는 사람"의 관점에서 읽어보았는가?
- [ ] 변수명/함수명이 의도를 명확히 전달하는가?
- [ ] 6개월 후의 내가 이 코드를 이해할 수 있는가?

### 3.2 체크리스트 보관
- [ ] 체크리스트를 `templates/completed/`에 `[YYYYMMDD]_[작업명].md`로 저장했는가?

---

## 체크리스트 사용 예시

```markdown
# [2025-05-26] 브랜드 등록 페이지 개발

## Pre-Flight
- [x] AGENTS.md 확인 — App Router 규칙 준수
- [x] DESIGN.md 확인 — rounded, container 규칙 확인
- [x] 기존 코드 탐색 — `(dashboard)/` 구조 파악 완료
- [x] 작업 범위: `/dashboard/brands/new` 페이지 + API POST

## Post-Flight
- [x] 빌드 통과
- [x] rounded-xl 적용
- [x] RLS 정책 확인 완료

## Review
- [x] 코드 가독성 확인
- [x] 체크리스트 보관 완료
```
